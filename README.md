## Installation

1. Clone the repository:

```bash
git clone https://github.com/zunair668/sqe-gradebook.git
```

2. Navigate to the project directory:

```bash
cd sqe-gradebook
```

3. (Optional) Create and activate a virtual environment:

```bash
python -m venv .venv
```

On Windows:

```bash
.venv\Scripts\activate
```

On macOS/Linux:

```bash
source .venv/bin/activate
```

4. Install project dependencies if a requirements.txt file is available:

```bash
pip install -r requirements.txt
```
